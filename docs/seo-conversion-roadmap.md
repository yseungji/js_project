# 검색 유입에서 견적 문의까지

목표: JS건설을 모르는 구매자가 표지판·지주를 검색해 제품을 확인하고 전화 또는 이메일로 견적을 문의한다.

1. 제품 상세 페이지 구체화 — 사진과 확인된 판매 범위를 제품별로 구분해 설명한다. 확인되지 않은 치수·재질·인증·가격·납기는 임의로 확정하지 않는다. 기초 설치형 금속 지주는 콘크리트 기초가 판매 구성에 포함되지 않는다.
2. 검색 의도에 맞는 페이지 구성 — 제품 상세를 먼저 고유하게 만들고, 표지판·지주 분류별로 충분한 독자적 안내가 준비되면 별도 분류 페이지를 검토한다. 단순 필터나 중복 문구만으로 페이지를 늘리지 않는다.
3. 문의 동선 개선 — 제품별 전화·이메일 문의를 쉽게 찾게 하고, 이메일에는 제품명과 수량·규격·납품 지역·희망 일정 등 필요한 정보를 담기 쉽게 한다. 실제 문의 수로 효과를 확인한다.

광고 등록은 사업자 인증이 가능한 시점에 다시 진행한다. 검색 순위나 문의 발생은 사이트 수정만으로 보장되지 않는다.

검색 유입 구조는 여러 개의 별도 사이트를 만드는 대신, 하나의 대표 도메인 아래에 고유한 제품 상세 페이지를 유지하는 방향으로 한다. 검색어와 제품이 맞는 상세 페이지로 유입시키고, 홈은 전체 상품 및 회사 신뢰 정보를 보여주는 길잡이로 쓴다.
